# HttpLocalServer 3.5.1

Apache-2.0 · 作者 github@nwdxlgzs

一个 C/C++ 原生 CLI，提供局域网 HTTP 服务：默认 FileTrans 文件传输模式，也可切换 Server 托管网页或 ZIP 工作区应用。

## 本版更新

- ZIP 应用静态资源使用有界热点缓存，同一资源的并发解压合并，按频率与大小决定缓存准入，空闲后回收。
- 缓存命中仍检查请求权限、私有模块边界与源文件版本。
- 复用可信脚本编译结果与空闲运行时；每次调用创建独立上下文及原生组件，异常、残留任务或资源超限时淘汰运行时。
- 增加 `--workspace-cache-mb`、对应 JSON 配置和脚本诊断信息；默认缓存预算 16 MiB，设为 0 禁用保留缓存。

Windows 发布程序已使用中性的构建路径重新编译，避免诊断字符串携带个人目录；附件校验值已同步更新。

## 提供的程序

| 文件 | 平台 |
|---|---|
| `HttpLocalServer-windows-x64.exe` | Windows x64 |
| `HttpLocalServer-linux-musl-x86_64` | Linux x86_64 / musl 静态版本 |
| `SHA256SUMS.txt` | 两个平台程序及四个宣传视频的 SHA-256 |

运行时只需对应平台的程序。首次使用默认共享当前工作目录、监听 `0.0.0.0:8000`、只读，预览默认启用；首次修改主机设置时才按默认规则生成配置。运行状态及上传内容独立保存在磁盘。

```powershell
# Windows：指定共享目录
.\HttpLocalServer-windows-x64.exe --root D:\Share --port 8000

# 托管静态网站
.\HttpLocalServer-windows-x64.exe server --root D:\Website --port 8080
```

```sh
chmod +x ./HttpLocalServer-linux-musl-x86_64
./HttpLocalServer-linux-musl-x86_64 --root ./share --port 8000
```

浏览器使用主机可达的局域网 IP 和所设端口访问。写入、登录口令、上传额度、TLS、ZIP 预览与 PCDN 按需要配置；ZIP 预览和 PCDN 默认关闭。主机设置、CLI 与配置文件的优先级及完整用法见仓库 README 和 `docs/`。

## 核验与边界

- 此版本已完成 Windows 和 Linux-musl 的针对性回归；报告位于 `docs/verification/release-v351.json` 及其引用文件。
- macOS 为源码适配，本次没有 macOS 或真实 Windows 7 设备的运行核验。
- ZIP 应用的 JS 分发仍然串行；本版改善缓存和初始化复用，没有改造成多 JS 工作线程后端。
- 性能对照为短时本机回环诊断，不代表局域网容量或持续高并发性能保证。
- Apache-2.0 适用于项目代码；第三方组件及制作素材遵循各自许可。执行程序的 `--licenses` 可查看内嵌许可声明。
