# IE11 手工验收

用户已于 2026-11-10 完成 2.2.0 的 IE 验收并反馈无问题，未提供 Windows / IE 的具体版本。以下保留可复用验收清单；2.2.1 新增标签重叠和多文件关注，自动验证保持 ES5 语法与权限测试，未宣称完成新版 IE 实机回归。

## 准备

在项目目录打开 PowerShell。测试目录必须是尚不存在的新目录；生成器仅依赖 Python 标准库。

```powershell
# 在仓库根目录执行
python tests\make_preview_fixtures.py .deps\ie11-fixture
.\dist\HttpLocalServer-windows-x64.exe --root .deps\ie11-fixture --port 18080 --write-mode isolated
```

保留服务端控制台，再打开 IE11（也可使用自行准备、仅本机保留的 `tools\LaunchIE.exe`），在地址栏输入 `http://127.0.0.1:18080/`。F12 确认文档模式为 **11**，关闭兼容性视图，使用 Ctrl+F5 刷新。网络面板开启捕获；控制台不得出现脚本语法错误。也可从另一台机器用控制台列出的真实局域网 IPv4 地址访问。

默认预览开启、懒缩略图关闭。可另外准备已确认 IE 支持编码的 MP3 或 H.264/AAC MP4；服务器不会转码。测试文件夹里的 WAV / SVG 用来观察兼容降级，不能把浏览器缺少解码器误判为 Range 失效。

## 浏览、导航和标签

1. 页面出现装饰红黄绿灯、在线文件下载标题、左下绿色连接胶囊、访问 IP 和权限信息。
2. 首屏显示“已加载 100”；向下滚动后出现后续资料文件。F12 元素面板中的文件节点数量应接近可视行数，不随已加载总数持续增长。
3. 列表与网格切换后是真正的不同布局；调整窗口至约 390px，工具栏收纳到更多菜单，页面不横向溢出。
4. 点击新建标签，最多 12 个；加号随标签排列。标签可拖动排序，活动目录不变。窄窗口中标签先缩小，再出现左右按钮，无滚动条覆盖。
5. 连续关闭多个标签，关闭后宽度短暂保持再展开；至少保留一个。根目录后退/前进/向上按钮按边界置灰，内部导航不会关闭浏览器页面。
6. 双击地址框空白处或按 Ctrl+L，输入 `/网页示例` 并回车；按 Esc 取消编辑。地址右侧向下按钮应列出同级文件夹。
7. 搜索“资料-14”，再清除搜索；排序、前进/后退和路径状态一致。

## 下载、ZIP 和记录

1. 下载中文文件，检查浏览器下载器中的名称和内容。右键目录“下载为 ZIP”，保存后用资源管理器或 7-Zip 打开。
2. `archive-fixture.zip` 应包含 `empty/`、`中文文件.txt` 和 `data.bin`；解压结果应与原目录一致。不能出现“超出范围的文件块”或损坏压缩包。
3. 下载记录出现条目，点“清除”后为空；刷新后仍为空。记录表示已交给下载器，实际完成进度由 IE 下载器管理。
4. 使用大文件下载后在浏览器下载列表暂停/恢复；如 IE 下载器不提供该操作，用 HTTP 校验独立验证服务端 Range：

```powershell
$r = [System.Net.HttpWebRequest]::Create('http://127.0.0.1:18080/download?path=/archive-fixture/data.bin')
$r.AddRange(65536,131071)
$s = $r.GetResponse()
$s.StatusCode
$s.Headers['Content-Range']
$s.ContentLength
$s.Close()
```

预期 `PartialContent`、`bytes 65536-131071/1024000`、`65536`。普通大文件下载与目录 ZIP 的 Blob 暂存是不同路径；IE ZIP 暂存受 256 MiB / 窄屏 64 MiB 限制。

## 预览与主机设置

1. TXT 可读；`.cpp` 等其他文本类型不显示文本预览。Markdown 显示粗体，原始 script 作为文字，危险链接不执行；JSON 可逐层展开，250 项数组分批显示。
2. PNG 可以适应窗口和 1:1。IE 的 HTML / SVG 主动文档应安全降级：侧栏给出提示，直接地址下载，不能执行共享文档来取得管理权限。现代浏览器另验网页相关 CSS、脚本和根路径 JSON 请求。
3. 已知兼容的音视频在侧栏和右键“新窗口打开”中均可播放/暂停、定位、调音量和倍速；关闭预览后停止声音。新窗口应是完整播放器，而不是失效裸文件页。不支持的编码应出现下载提示。
4. 主机面板勾选“预览后生成缩略图”，应用后预览 PNG，文件图标应变为实际缩略图；另一个客户端也跟随开关，但只显示自己预览过的内容。主机关闭后，各可见客户端约 3 秒内清除。
5. 主机面板关闭“允许文件预览”，所有客户端隐藏预览入口，直接 `/preview`、`/view/...` 请求被拒绝；再打开恢复。验证公告、共享名称更新。主机在列表右键两份文件并分别标记关注，顶部应同时出现两个条目，列表均有星标；右键任一文件或顶部条目取消，只移除该项。重命名文件或父目录时标记应跟随，删除时清除。
6. 右上角三个图标切换系统/白天/夜间；IE 不支持系统配色探测时，系统项回退白天，手动选择仍有效。

## 权限与上传

本机在 isolated 模式可管理整个测试目录。另一台机器应只可写 `/_clients/<实际IP>/`，左栏有专属管理目录提示；不能修改他人目录或管理共享根目录。验证上传、创建、重命名、删除，以及改扩展名后的建议确认。切换 readonly 后所有写操作拒绝；shared 模式所有访问者可写。IP 上限可先调到 1，确认第二个不同 IP 被拒绝，全部连接释放后可恢复。

仅主机可见并使用设置面板；远端直接请求 `/api/admin/settings` 应返回 403。通过主机调整上限后重新验收，不要把所有页面关闭后仍在运行的下载连接遗漏。

遇到异常，请记录 Windows / IE 版本、文档模式、URL、操作步骤、F12 第一条脚本错误及对应请求状态。验收完成后 Ctrl+C 停止服务，测试目录按需保留。

## 2.3 增补核对

1. 本机侧栏与更多菜单显示“设置”，远端设备看不到该入口，直接请求管理接口仍为 403。
2. 在支持的 MP4/MP3 上检查新播放器的进度、时间、音量、倍速、前后跳转和全屏进出；暂停画面不拉伸，退出全屏回到原侧栏。页面未获全屏许可时应显示提示。
3. 把本地文件拖到目标文件夹：共享模式在该目录出现文件；独立模式在 IP 目录外投放时进入自己的 IP 根目录，目录内投放则进入相应子目录。本机管理员的拖入规则也如此。
4. 共享模式把可写文件拖到另一个目录或面包屑，源位置移除、目标出现；只读时不可移动，同名目标不覆盖。
5. 再次上传同名文件时，先出现跳过/改名/替换版本选择。两台机器同时替换同一版本时只有一个成功，另一台收到冲突，不能静默覆盖。
6. 主机打开懒缩略图后，视频刚打开的黑帧不应成为图标；播放或拖动到有效画面后才出现保持比例的缩略图。主机关闭后所有页面清除。
7. 在资源管理器给测试文件、文件夹设置隐藏属性，默认列表和搜索都不显示；更多菜单开启“显示隐藏文件和文件夹”后显示，关闭后恢复。另一台设备不跟随此偏好；刷新当前浏览器仍保留。普通点开头文件在 Windows 不应自动隐藏。
8. 浅色、深色分别进入全屏，核对控制栏和留白对应主题，播放/暂停/重播图标均清晰。弱网卡顿时不会只恢复一两帧又反复停住；缓冲中点击暂停后不能自行重播，拖动到其他时间应取消原来的缓冲等待。接近结尾不能等待超过剩余时长的缓冲。

以上是可复用步骤，2.3 未由自动工具执行 IE 实机核验。
## 本轮增量核验

- 独立权限写入打开页面和“我的文件夹”，确认服务器没有凭空创建 IP 目录；普通文件上传成功后才出现对应目录。
- 上传成功后填写姓名。主机设置中审核之前，其他访问者不能看到姓名；审核通过后显示姓名胶囊。
- 删除 IP 目录中的最后一个文件，保持任意标签仍在该目录或后代目录，确认不被清理；标签离开后再检查自动回收。直接关闭页面的兜底等待约 45 秒。
- 页面高度缩到 400px 左右，侧栏滚动后仍可访问设置与连接信息，不能覆盖“我的文件夹”等导航。
- 从系统外部新增或修改当前目录文件，默认只显示刷新提示；在更多操作里启用自动刷新后再次修改，应在下次检测时更新。
- IE11 的普通文件选择、上传、下载、姓名提交及更新提示为本轮兼容目标；IE11 没有网页目录选择/目录遍历接口时，“上传文件夹”给出提示。文件夹拖入和目录选择使用具备这些接口的现代浏览器核验。


## 2.4 增量核验

- 系统、白天、夜间三个按钮常驻右上角；分别选择后页面和播放器使用相应配色，更多菜单没有重复配色项。
- IE11 没有 File System Access API 时不显示“挂载本地文件夹”和“下载到本地文件夹”，原有上传/ZIP 继续工作。
- 用 `--mount-root /Computer` 启动，Windows 下进入 Computer 可以看到 C、D、E 等可访问盘符；只读映射的上传、重命名和删除应不可用。
- 主机设置的统一上传额度支持 MB/GB，单独 IP 输入支持 `IP=数值MB/GB`；额度耗尽时应显示提示，0 恢复不限。
- 现代浏览器另外验收目录授权、后台复制、按需优先复制、关闭提供方后主机已有副本下载，以及直接写入本地目录。原生授权弹窗由用户完成。

## 2.5.1 增量核验

本轮完成 ES5 解析和移除现代 API 的启动测试，以及现代浏览器布局核验；未运行 IE 实机。静态检查命令：`node --expose-internals tests/ie_compat_test.cjs`。

- “更多 → 访问地址与二维码”应按浏览器可视区域水平、垂直居中；缩矮窗口后弹窗内部可滚动，关闭按钮仍能访问。
- 主机设置的每 IP 累计上传额度数值和紧凑 MB/GB 选择框同排，窄窗口也不换行。
- 右上角切换配色时选中胶囊平滑滑动，当前图标有轻微缩放；页面颜色渐变。IE 中键盘 Tab 焦点可见；不支持系统配色探测时仍能手动切换。
- Markdown 的标题、列表、表格与粗体正常；控制台不出现 Set、Symbol、Array.from 或 Promise 未定义错误。普通上传、下载及 ZIP 继续可用，现代目录 API 入口在 IE 中隐藏。
- 设置面板和姓名审核/登录封禁区域的间距正常；IE 不支持粘性定位时，设置面板作为整体滚动，头部和底部不会重叠内容。
