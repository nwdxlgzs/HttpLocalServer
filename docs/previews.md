# ZIP、Office 与 PDF 预览

ZIP 预览默认关闭，FileTrans 和 Server 的管理界面均可使用。CLI：

```text
HttpLocalServer --zip-preview off
HttpLocalServer --zip-preview host
HttpLocalServer --zip-preview client
```

主机设置的“ZIP 压缩包预览”支持即时切换，写入 config.json 的 `options.zip-preview`。CLI 的启动覆盖规则保持不变。总预览开关关闭后，ZIP、Office 和 PDF 一并禁用。

预览占用管理器内部标签页，与目录标签共用 12 个名额。达到上限时提示先关闭标签。关闭预览会终止浏览器处理器、释放资源，并请求清理相应主机 ZIP 会话。新窗口文档预览也跟随主机策略。

## ZIP 的三种模式

- `off`：不显示 ZIP 预览入口，主机拒绝解压接口。
- `host`：主机检查 ZIP/ZIP64 中央目录，只在请求文件时解压到私有暂存。重复请求复用校验后的内容；浏览器支持 Range 请求。适合关联资源和碎文件较多的网页。
- `client`：先下载压缩数据，在独立 Web Worker 内检查、按需解压。主机只传输原 ZIP，不解压，也不接收客户端展开的数据。包内网页使用独立的 opaque-origin 沙箱，HTTP 环境也可以使用。

主机模式仅支持已在主机可读取的普通文件。浏览器挂载尚未完成主机副本时，应先完成该文件的普通下载/复制镜像，再打开主机 ZIP 预览；客户端模式可以通过普通下载票据读取挂载文件。

两种模式均不递归展开嵌套 ZIP。支持 STORE、DEFLATE 和 ZIP64；拒绝加密、分卷、不支持的压缩算法、符号链接/特殊文件、含糊文件名、路径穿越、重名冲突、本地头与中央目录不一致、条目重叠和尺寸越界。文件名接受 UTF-8 和 ASCII；其他旧式编码需先重打包成 UTF-8。

声明体积只用于提前拒绝，不能代替实际解压检查。实际展开时再次限制输出量并校验 CRC；失败内容不会发布到共享目录。源文件版本变化会终止预览。

## 固定安全预算

| 项目 | 主机 | 浏览器 |
|---|---:|---:|
| 压缩包大小 | 512 MiB | 64 MiB |
| 单文件展开大小 | 32 MiB | 32 MiB |
| 包内声明总展开量 | 256 MiB | 256 MiB |
| 条目数 | 8192 | 8192 |
| 中央目录 | 4 MiB | 4 MiB |
| 路径深度 | 32 | 32 |
| 声明展开比 | 最大 `max(1 MiB, 压缩大小 × 200)` | 相同 |
| 单会话累计展开工作 | 256 MiB | 256 MiB |
| 单次处理 | 2 秒检查/解压循环预算 | 5 秒后终止 Worker |

主机使用独立的单工作线程，队列最多 32 项；普通下载线程不执行 ZIP 解压。最多 16 个会话、每 IP 4 个；中央目录索引总预算 16 MiB，展开缓存总预算 128 MiB，每个会话最多缓存 512 个文件。会话空闲 120 秒后回收；删除失败的缓存继续占用额度。重启会清理上次 ZIP 私有缓存，不恢复旧预览授权。

浏览器主页面只允许一个客户端 ZIP 预览保留压缩数据预算。独立窗口各自受 64 MiB 限制。浏览器本身的进程资源、第三方页面脚本的运行时间和用户自行下载后的解压行为不由主机解压器控制。

## 包内网页

主机模式使用 IP、登录授权版本、原 ZIP 版本绑定的只读 capability URL；根路径资源映射回该 ZIP。opaque-origin iframe 与 CSP 禁止访问管理接口、外部网络、表单提交、插件与子框架。页面普通相对资源、根路径 CSS/脚本、图片及 fetch/XHR 可以使用。

客户端模式将静态资源按依赖顺序传入隔离页面，在隔离页面内创建 Blob URL。只读 fetch/XHR 通过消息桥按需读取同一压缩包；最多 8 个并行消息请求、128 次资源读取、64 MiB 资源量。网页正文最多 2 MiB、CSS 1 MiB、DOM 20000 个元素。CSS url()/@import、常见静态资源、内联脚本和事件支持转换；复杂模块 import 图、Service Worker、子框架以及需要真实站点后端的网页不能视为完整网站托管。需要完整路径语义时选择主机模式。IE11 保留 ZIP 浏览与下载，不执行包内网页。

原文件下载不经过网页文本重写；预览中的 HTML/CSS/脚本资源才应用 URL 调整。

## Office

浏览器使用 **@silurus/ooxml 0.89.10** 官方预编译 Wasm（MIT）；服务端及项目构建不引入 Rust。支持 DOCX/PPTX/XLSX，带选择文字、选择单元格、复制、翻页、缩放和查找。使用本地打包资源，不依赖 CDN 或 Google Fonts。所有预览资源压缩嵌入单文件程序，打开对应类型时才请求。

文件上限 32 MiB；先在可终止 Worker 中检查 ZIP 容器，再进入库解析。库限额：单条目 16 MiB、总展开 128 MiB、4096 个条目；工作表最多 100000 行/200000 单元格，拥有的 UTF-8 数据 16 MiB、JSON 32 MiB；图像解码采用 32 MiB 严格预算。解析 worker 超时 10 秒，页面加载上限 20 秒。

上游 Wasm 使用多表等特性，不能直接通过当前 Binaryen wasm2js 转换器获得可用的 IE 引擎。因此未捆绑一个声称能运行这些 Wasm 的通用 JS 虚拟机。无 Wasm/模块能力的浏览器自动按需加载纯 JS 基本预览：Word 正文、表格与常见内嵌图片、PowerPoint 幻灯片文字与图片、Excel 工作表值和单元格。保持可复制，复杂版式、图表、公式排版和原始分页不保证一致。旧浏览器 XML 禁用 DTD/实体声明，单 XML 4 MiB、50000 节点、128 层；工作表最多 10000 数据行/100000 单元格，分批显示。

识别到 OOXML/PDF 内容但没有对应后缀时，也使用检测到的类型选择预览引擎，不改动原文件名。

## PDF

使用 **PDF.js 6.5.438**（Apache-2.0），支持按页渲染、文字层选择复制、翻页、缩放、页内查找和密码输入。普通现代浏览器支持 Range，关闭自动预取；上限 128 MiB、5000 页、单张画布 2M 像素、图像 8M 像素，超时后终止 worker。

旧浏览器按需加载同版本 ES5 构建，以及 Promise/集合、Streams、fetch、文本编码、DOMMatrix、Canvas Path2D/变换和 AbortSignal 兼容代码。禁用 Wasm，使用独立 JS PDF worker；旧浏览器 PDF 先有界下载，最多 32 MiB。没有宣称当前最新版 PDF.js 原生支持 IE；这是项目维护的转换/兼容构建，真实 IE11 仍需人工核验。

## 3.3 阅读与编辑

预览动作以内容推断结果为准，不要求文件后缀正确。选择文件时会按需识别并更新菜单；识别结果按文件版本缓存。ZIP 主机资源也使用实际内容 MIME，错误后缀的外层 ZIP 可以正常打开。

Word 使用连续滚动和邻近页面渲染；PDF 保留页壳，通常只绘制附近四页，每张画布不超过 2M 像素，支持页码定位、缩放、原生文本选择。PDF 查找覆盖已渲染的附近页面。PPT 的当前导航、缩放与播放行为见下方 3.4 节。当前上游解析/渲染接口不支持 PowerPoint 动画与页面切换效果，本项目没有模拟原文件未解析的动画。Excel 保留单元格范围拖选，并增加可独立拖选字符的内容栏。选中后右键提供文字 / 单元格和页面或所选元素图片复制；优先使用 PNG 图片剪贴板，不可用时尝试兼容 HTML 图片复制，再回退保存 PNG。

ZIP 内 Markdown 禁止原始 HTML，图片和文档链接限定在同一压缩包的有效相对路径内；两种 ZIP 模式均支持，不依赖外网。图片关联资源共 16 MiB、最多 64 项。压缩包自身的安全预算继续适用。

更多检测为文本的源码、配置、日志等可预览；有写入权限时在预览或右键菜单打开编辑器。完整编辑上限 2 MiB，保存沿用上传权限、额度、原子替换和原版本检查；冲突时保留编辑内容，提示重新打开并合并。非 UTF-8 文件保留解码后的只读预览，防止静默改编码。Monaco 0.57.0 为 MIT 许可，仅在现代桌面浏览器按需加载，已内置简体中文及 Modern Dark/Light 配色；手机和 IE11 使用普通文本编辑器。尚未保存时关闭应用内标签有确认提示。


## 3.4 预览工作区

所有文件类型均在管理器新标签或独立窗口预览，管理器最多保留 12 个标签。文本、图片、网页、音视频沿用既有安全预览和播放器，预览标签不再压缩文件列表侧栏；打开后收起文件管理命令与目录导航，主题与权限继续跟随主机设置。内嵌图片/视频预览生成的懒缩略图只回传当前管理器页面的有界内存缓存；主机关闭时清理。内嵌预览复用主页面的策略同步，不独立轮询或注册 PCDN 提供方。

文档预览不再保留常驻状态条或引擎介绍。加载指示在内容就绪后消失，复制、查找和错误使用短暂消息。手机查找按按钮展开，不持续挤占阅读区域。工具栏会换行，页面区域随实际剩余空间布局。

PPT 默认适合完整页面，缩略图按原始长宽比排列、按可见范围渲染和回收画布。桌面可收起导航，手机默认收起，以浮层打开，选择页面后自动收起。顶部缩放一行同时提供放映与自动播放按钮，可设 3/5/10/15/30 秒间隔。连续快速翻页保留最后目标，自动播放等待页面渲染后计时；离开预览标签会暂停。放映支持全屏或浏览器不允许时的窗口内全屏、Home/End、方向键、PageUp/PageDown、空格翻页和 Esc 退出。触摸设备在完整页面模式支持横向滑动翻页；手动放大后保留内容平移。文字选择不被普通点击翻页抢占。当前 Silurus 不提供原文档动画/切换的解析与播放，这些效果不在此次支持范围内。

Word 不再把首次容器宽度固定给引擎，宽度、整页与实际大小可切换。PDF 连续页面按各页实际尺寸适配可用宽度，横竖混排不再沿用第一页的缩放；手动缩放后保留自定比例。两者均随容器尺寸和工具栏高度变化重排，保持有界邻近页面渲染。

Excel 初始采用实际大小，支持输入单元格/区域地址跳转。选中合并区域内部会扩展至整个合并单元格，内容栏读取主单元格，复制时不重复填充被覆盖的格子。普通多格复制保留行列和中间空格位置。无 Wasm 降级以 HTML rowspan/colspan 表示合并区域，跨 100 行分页或 32 列分组时裁切显示并保留主格文字；最多 4096 个合并区域，展开行工作量上限 100000。复制按钮的兼容路径保留原选区与焦点。

验证：`python tests/viewer_layout_browser.py <程序>`，可追加 `--https`。包含实际 Chromium 桌面、触屏横竖屏、快速导航与自动播放、Word/PDF 容器缩放、合并选择和剪贴板、无 Wasm 跨行跨列降级、预览标签/新窗口及懒缩略图回传。原有通用预览测试仍覆盖 PDF/Office 的文字和图片复制、ZIP 关联资源及编辑器保存。

3.4.1：PDF.js 的文字层使用其实际字体高度、横向缩放和旋转参数，缩放后的可选字形跟随页面。PPT 文字层按视觉行从上到下、同行从左到右排列，保留原渲染和查找索引；跨图文选择支持 HTML/纯文本剪贴板。图片使用当前页已渲染表面的 PNG 裁片，保留可见效果；只保留当前页，最多 32 项、累计 2 Mi 像素和 4 MiB 图片数据，不额外解码原始大图。较窄屏幕将页码与放映按钮放在第一行，缩放与播放间隔放在第二行。
