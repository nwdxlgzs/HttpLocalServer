# 挂载与上传额度（2.5）

`--system-root` 将系统根作为共享视图，Windows 根目录合成可访问盘符 C、D、E 等，Linux/macOS 显示 `/`。`--mount-root /Computer` 将同一视图放到子目录；`--mount-volumes /Volumes` 枚举 Windows 盘符、Linux 已挂载的块设备挂载点（以及根）、macOS `/Volumes` 与根。`--mount /名称=物理路径` 可重复添加任意已存在目录或分区，默认只读；`--mount-rw` 开启挂载本身的写能力，仍需同时满足全局写入模式与独立 IP 约束。主机“更多 → 挂载主机目录或分区”可动态添加路径。

映射根及其虚拟祖先不能被删除/移动，直接重命名 API 的跨映射移动返回冲突，网页使用有检查点的复制/版本核对/条件删除完成跨映射移动；实际文件继续使用安全打开、版本固定续传、COW 和热点缓存。系统根模式默认关闭递归索引，进入主机挂载目录后按需进行有界目录搜索。挂载不向操作系统安装驱动，也不使用符号链接突破共享根。

## 浏览器目录

浏览器支持目录句柄、迭代器及安全上下文时，工具栏显示“挂载本地文件夹”。只读共享中可挂只读目录，独立模式的远端仅可挂在自己的 IP 目录内部，主机管理员可选择全共享目录；共享模式允许选取当前共享路径。只读模式的远端使用自己的 `/_mounts/<IP>/` 虚拟位置。读写挂载只在浏览器提供写接口且主机允许写入时显示选项，并须取得实际 readwrite 授权；浏览器不提供原生移动接口时，移动与重命名均使用复制/条件删除回退。普通 HTTP 局域网 IP 通常不满足目录选择器安全上下文要求；无法使用时不显示入口，普通文件/目录上传和 ZIP 下载继续可用。

目录句柄保留在挂载页面，后台逐文件流式复制到主机；其他访问者请求尚未复制的文件时，优先触发该文件复制，等待完整版本在主机发布后再发下载链接。相同文件的后台复制和按需复制合并；已复制且源版本未变时不重复上传。正文下载由主机现有大文件/Range/COW/缓存通道分发，不通过提供方浏览器逐块中继给每个下载者。后台每次处理一个文件，与前台优先复制并行；一次最多遍历 100000 项、64 层，目录元数据和副本版本表均有内存上限。在线浏览器目录的文件名搜索递归检查当前挂载目录及后代，受同样的 100000 项、64 层和 8 MiB 元数据约束，列表/搜索均按需分页；主机映射的目录搜索最多检查配置的索引项预算。

浏览器挂载最多全局 64 个、每 IP 8 个，提供方身份绑定 TCP IP 和专用随机密钥；轮询只携带操作元数据，一页只发一个请求，空闲约 1 秒间隔。页面关闭或停止应答 45 秒后标为离线；已有主机副本仍可浏览和下载，未复制内容需提供方恢复。挂载页面应保持运行，浏览器休眠/后台节流可能使它暂时离线。

副本以私有临时文件写入，并在完整上传后原子发布到挂载时选定的共享路径，例如 `/资料/照片/a.jpg`。卸载移除浏览器映射并终止尚未完成的写入，已完成文件在原路径保留，可直接浏览、下载或重新启动后继续使用；无需恢复挂载。2.4 版本遗留的 `.hls-mounts/<挂载ID>/` 私有副本不会被自动删除，其原虚拟路径没有跨进程记录，必要时由主机人工迁出。实时挂载列表可能包含尚未复制的文件，源端删除后已有副本仍可能在离线视图出现，因此离线视图是副本状态，不宣称完全同步。

读写挂载逐块写浏览器私有流并在完成时发布，再复制到主机。源目录上的外部修改依赖文件版本检查，不能等同事务文件系统。尚未发布的浏览器写入在取消或超时后 abort。写入失败的新文件可能保留空占位文件，完成文件与主机已有副本不会因此被删除。

## 目录直接保存

具备安全上下文、`showDirectoryPicker`、`getFileHandle` 和 `createWritable` 时，更多菜单及目录右键提供“下载到本地文件夹”，主下载按钮对目录也优先使用此路径。选取本地位置后按目录层级创建目标，每次以 256 KiB Range 块读取已固定版本的文件并写入本地，包含空目录，不生成 ZIP，也不把整个文件放进 JS Blob。

本地同名文件逐个询问跳过或替换。替换流完成前保留旧文件，并在关闭流之前再次核对原文件元数据；源服务器版本改变、范围不匹配、取消或网络失败会中止当前文件。已经完成的文件保留。每次最多 100000 项、128 层、16 MiB 遍历元数据。浏览器不支持时不显示直接保存入口，继续提供既有 ZIP 方案。

## 每 IP 额度

`--ip-upload-mb N` / `--ip-upload-gb N` 为每个实际 TCP IP 设置累计上传额度，默认 0 不限制；`--ip-upload-limit IP=512MB` / `IP=5GB` 为指定 IP 覆盖统一额度，可重复最多 256 次。主机设置面板可修改统一数值与 MB/GB 单位，也可逐行设置单独 IP 的额度。单独值为 0 时，该 IP 不限，不受统一值限制。MB/GB 按 1024 进位。

额度持久化累计接收量，重启后保留，主机可手动清零，包括普通上传、中断上传已经收到的部分、挂载后台复制、再次上传的新版本和服务端复制实际写入的字节；删除文件不返还已消耗额度，重启进程继续计量。读写挂载里，访问者写入浏览器源目录的传输计入访问者，原生提供方后台复制计入提供方；可恢复挂载上传直接复用主机已有暂存字节发布副本，该次上传不会因回传再计量。

已知 Content-Length 的上传先预留剩余额度，取消后释放未到达部分；chunked 上传逐块检查，不能通过并发或省略长度绕过。网页先按文件大小探测额度，超额不发送文件正文；原始 HTTP 客户端可用 `Expect: 100-continue` 避免发送被拒绝的大正文。后台复制遇到额度耗尽时暂停，已复制内容仍可使用，主机可提高额度后重新挂载继续复制。

独立 IP 模式下，主机管理员不受 IP 目录边界、逐 IP 上传额度和独立目录数量限制，上传保留所选目标位置；显式只读挂载和单文件大小预算仍有效。`--strict-host` 可将管理员身份限制到 `127.0.0.1` 与 `::1`。
