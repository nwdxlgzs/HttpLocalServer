# 3.1.0 Server 与文件传输

两个模式共用权限、登录、冻结保护、Range、压缩、流控、上传续传和持久化状态。FileTrans 在 `/` 显示管理器；Server 在 `/` 托管网站，在 `/_hls/` 提供同一管理器。默认仍是 FileTrans、`0.0.0.0:8000`、只读、允许预览。

## 传输与批量操作

支持 Ctrl/Cmd 多选、Shift 范围选择、空白区域框选和 Ctrl/Cmd+A。全选按 100 项分页获取，最多 10000 项；文件列表继续复用虚拟行，不为所有文件生成 DOM。批量工具条提供下载、复制、移动和删除，复制内容可跨管理器标签或同源浏览器页粘贴。

可写目录的“新建”菜单和空白处右键支持新建文件或文件夹。新文件为空文件，可自选名称；同名内容不会被覆盖。独立 IP 权限和只读设置同样适用，读写浏览器挂载也支持创建。

任务中心提供 1–4 个公共传输并行槽（默认 2）、排队、暂停、继续、失败重试、速率、预计剩余时间及已结束任务清理。同名策略为逐项询问、跳过、替换当前确认版本、保留两份。服务端最终版本检查失败会拒绝覆盖，需重新确认目标。批量 API 每批最多 256 项，先检查所有路径与冻结项，再逐项返回结果；中途文件变化可能产生部分成功，不承诺跨文件事务。

上传、挂载后台复制、ZIP、本地文件夹保存、P2P 和复制在任务中心显示。原生浏览器下载只记录“已发起 · 浏览器管理”，不展示虚构的完成进度。上传、浏览器挂载上传、后台复制、ZIP、目录保存、复制、批量操作及 P2P 下载共同竞争并行槽；原生浏览器下载和 PCDN 被动发送不占页面任务槽。暂停在安全处理边界让出槽位，恢复重新排队。等待同页挂载提供方复制时让出父任务槽位，避免父子任务互等。


目录保存、ZIP 和复制先按每页 100 项扫描有界清单，得到总字节数后显示整体进度和 ETA；扫描阶段使用不确定进度动画。清单最多 100000 项、128 层、16 MiB，分页目录戳变化会停止。复制的单文件进度由主机实际写入偏移采样，不依赖猜测。清单在 IndexedDB 中单独保存一次，检查点只更新游标与当前项目，避免碎文件传输反复序列化整份清单。

支持 IndexedDB 与文件句柄持久化的浏览器可在重开页面后，从任务中心点击“继续任务”，重新授权原输出位置。复制每处理 1 MiB 保存目标续传会话，恢复时向主机读取实际偏移，再从对应源版本继续；丢失提交确认可以重放回执。目录直存在本地 `.hls-download-<任务>` 暂存目录中保存已提交块，首块 256 KiB，其后每块最多 16 MiB；源网络请求每次最多 256 KiB。恢复核对暂存大小、修改时间与输出版本，完成后一次 COW 发布并删除暂存。未提交块最多重取 16 MiB，已提交前缀不重取。取消会清理当前暂存目录。

ZIP 在访问者浏览器执行压缩，支持文件内部的 CRC、DEFLATE 字典/位置及 ZIP64 目录检查点。磁盘 ZIP 从 32 MiB 起按增长间隔提交，暂停时提交；没有本地写盘 API 时，浏览器将压缩块送入主机私有暂存，首个文件内检查点从 256 KiB 起，其后每 1 MiB 输入保存一次压缩器状态，最终交给原生浏览器下载，支持 Range。不会把整个 ZIP 保存在页面内存，也不在服务器压缩目录。私有日志在 SQLite 中与字节检查点原子提交；无 IndexedDB 时可从该日志恢复。每个任务的检查点串行提交，避免旧确认覆盖新进度。

浏览器挂载上传先以 1 MiB 分片存入主机私有暂存，页面重开后重新选择源文件，校验全部已确认前缀的 SHA-256 链后继续。源文件已全部暂存时，可直接继续发布。提供方以每次最多 256 KiB 拉取暂存字节、COW 写入，再返回版本；主机直接使用已有暂存字节发布公开副本，提供方不必再次上传相同内容。丢失发布确认时核对目标完整内容，拒绝覆盖已改变的内容。P2P 磁盘任务继续保存输出句柄，恢复时校验源版本并逐块验证本地前缀。浏览器不能在页面重开后擅自取回文件权限；缺少 FileReader/Blob 切片的极旧浏览器仅保留 PUT 回退。

恢复信息绑定主机共享命名空间和访问者 IP；同一网址换了共享根目录会拒绝旧任务。输出或暂存被其他程序修改时拒绝覆盖。浏览器文件提交与数据库不具备跨系统事务：目录目标提交后若来不及保存检查点，恢复会将其与本地暂存逐字节核对；相同则确认完成，不同则保留已有文件。

本地目录保存、上传、复制与批量移动共用同名策略与串行询问。跨主机/浏览器挂载移动采用复制、核对目标回执、按原版本删除源文件；文件夹从后代向祖先仅移除空目录，新增、改变或跳过的内容保留。浏览器同挂载原生移动接口可用时保留快捷路径，覆盖与跨挂载使用复制/删除回退。提供方网页修改操作串行执行；外部程序的写入仍通过版本检查拒绝覆盖。

浏览器支持 FileReader 与 Blob 切片时，普通上传使用 1 MiB 分片；旧浏览器保留流式 PUT 回退。普通 PUT 接收先填充有界块，再进行额度持久化和磁盘写入，避免每个 512 字节网络碎片都触发同步刷盘；连接提前关闭时，已收到的短块仍计费且不发布。服务器把续传分片刷到私有暂存文件，再持久化已确认偏移；重发已确认的相同分片不重复写入或计费。页面重开后在任务中心重新选择原文件，也可重新选择同一批文件夹来匹配续传。浏览器不能在页面重开后擅自取回磁盘文件权限。

快速指纹包含大小、修改时间与首尾样本；恢复后另逐块计算整个已确认前缀的 SHA-256 链，校验中部变化；支持时在 Worker 中计算，旧浏览器有界让出主线程。服务器提交时再校验暂存内容的同一哈希链。全程有界读块，不把大文件整体读进内存。最后通过 COW 发布，目标版本变化会拒绝覆盖。提交回执在最多 10 分钟、最近 1024 条的窗口内可重放，不会再次发布；超过窗口返回过期，不会主动覆盖新版本；崩溃发生在发布与记录之间时会核对目标内容。

未完成上传默认保留 24 小时，可用 `--resume-hours 1..168` 调整；`--resume-mb` 同时控制未完成上传预留与私有传输暂存的合计大小，默认 65536 MiB，最多 1024 个在途会话、每 IP 16 个；完成回执会按容量和时间淘汰，不限制长期上传文件总数。私有传输暂存最多 128 个、每 IP 8 个，单个日志最多 4 MiB（解包最多 32 MiB），沿用 `--resume-hours`；完成 ZIP 为保留原生续传机会，在到期或手动取消后清理。任务取消或过期会清理暂存文件；暂存额度不包括最终目标和 COW 发布所需的额外磁盘空间。挂载重新授权后，续传能力可在同 IP、同目标和有效提供方证明下重绑；已经复制完成的文件继续留在主机。

## 状态与回收站

运行时会创建 `.hls-state-<共享根标识>` 私有目录。默认放在配置文件旁，`--no-config` 时放在共享根内；可用 `--state-dir PATH` 指定持久可写位置。SQLite WAL 保存上传进度、配额、姓名申请与审核、登录失败/封禁和回收站记录。同一状态目录只允许一个进程使用。`--no-config` 仅关闭配置 JSON 的加载/保存，不关闭这些运行状态。搬迁或备份状态时先停止服务，完整保留该目录与相关共享文件。

累计上传额度在重启后保留。主机设置显示各 IP 用量，可以手动清零；仍有额度预留的上传时拒绝清零。重复的已确认分片不重复扣额度；接收后发生存储错误的流量可能保守计入用量。本机在独立 IP 模式下继续享有管理员豁免。

`--recycle-bin` 开启回收站，默认关闭。主机面板也可切换，默认保留 7 天、容量 1024 MiB；对应 `--recycle-days`、`--recycle-mb`。删除时在文件所在卷的 `.hls-trash` 私有目录中原子移动，避免跨盘复制或静默永久删除。满额时拒绝本次删除，主机可清理或扩大容量；超出保留期按有界批次清理。恢复不覆盖现有名称，冲突时可选择其他位置，原挂载和权限仍须有效。

主机可管理所有回收项；独立 IP 访问者只管理自己的目录项，共享模式远端只管理自己删除的项目。浏览器提供方的原始目录不在主机磁盘回收范围内，删除仍由提供方执行。私有状态、配置、脚本和 TLS 私钥不能通过管理器、网站、挂载别名或文件接口读取或修改。冻结项默认隐藏，不依赖操作系统隐藏属性；勾选“显示隐藏”后以名称与“冻结”标记展示，整行/卡片斜纹遮罩在深浅色和 IE11 下均有明确禁用反馈。

## 流控

| 参数 | 默认 | 含义 |
|---|---|---|
| `--upload-kbps` | 0 | 主机接收文件 KiB/s |
| `--download-kbps` | 0 | 主机发送文件 KiB/s |
| `--ip-upload-kbps` | 0 | 一个 IP 共用的上传 KiB/s |
| `--ip-download-kbps` | 0 | 一个 IP 共用的下载 KiB/s |
| `--ip-transfers` | 0 | 一个 IP 的传输并发数；全局 `--max-transfers` 仍生效 |

0 表示关闭该项限制。主机面板可即时调整。多个连接共用 IP 令牌桶，启用总限速时按近期实际请求数据的 IP 分摊；取消不预占未来令牌；socket 使用异步定时器等待，不休眠占用 I/O 线程。达到并发上限时返回 429，上传会有界退避重试。HTTP/HTTPS 使用同一调度；压缩下载按实际压缩后字节调度。浏览器之间的 WebRTC 流量仍由 PCDN 页面限速控制，不计入主机网卡限速。

后台文件复制和续传发布每处理至多 4 MiB 重新排队，让其他文件读写工作有机会运行。主机设置展示连接、收发总量/采样速率、内存和热缓存命中/回收信息。

## Server 托管参数

```text
HttpLocalServer server --root ./site --default-documents index.html,index.htm
HttpLocalServer server --root ./site --spa-fallback /index.html
HttpLocalServer server --root ./site --response-header X-Site=LAN --error-page 404=/404.html
```

SPA 回退仅用于 404、无扩展名路径且请求接受 `text/html` 的情况，缺失的脚本、样式和图片不会错误返回 HTML。自定义错误文件位于共享命名空间，沿用冻结、挂载和读取检查。自定义响应头可重复指定 `名称=值`，禁止换行与传输、认证、Cookie、连接等保留头。JSON 对应 `default-documents`、`spa-fallback`、`response-header`（数组）、`error-page`（数组）。

## QuickJS-NG

内置 QuickJS-NG 0.18.0，MIT 原始声明随 `--licenses` 输出。使用 `--script PATH` 显式加载可信主机脚本；上传的 `.js` 不会自动执行。示例见 `examples/server-hooks.js`。脚本源在启动时载入，修改后重启生效。源码上限 1 MiB、结果上限 64 KiB，默认每次 16 MiB JS 内存、32 KiB JS 栈（兼顾 musl 的小线程栈）、50 ms CPU/墙钟中断预算、4 个并行调用；可用 `--script-memory-mb`、`--script-timeout-ms`、`--script-concurrency` 调整。隔离钩子不提供 OS、子进程、网络或任意磁盘绑定。3.5 新增有界内置组件及 WAMR，接口与兼容范围见 [QuickJS/Wasm](quickjs-wasm.md)。

每次调用使用新的上下文和原生组件，调用间不共享可变全局对象、原型、SQLite 数据库或 Wasm 实例；不能依赖脚本全局变量保存业务状态。脚本失败、超时或资源不足会返回错误，服务继续接受后续请求。同步钩子不接受 Promise 返回值，也不执行 Promise 后续任务。

3.5.1 起，普通 `--script` 源码在启动时编译一次，仅在本进程内复用可信字节码；内置 Wasm JS 引导也复用编译结果。不会从客户端或磁盘加载预编译 QuickJS 字节码。每次调用仍执行顶层初始化；复用解析结果不代表保留业务状态。

独立运行时外壳按需创建并独占借用，最多保留 `min(script-concurrency, 8)` 个空闲外壳。上下文释放后收集循环引用；脚本异常、超时、待执行任务、残留分配超过 1 MiB 或外壳使用满 256 次时销毁外壳，避免旧上下文/任务持有失效原生绑定。空闲外壳随 `--thread-idle` 到期释放。每次调用仍有独立内存、栈、并发和执行期限检查；池不会让一个 Runtime 同时在多个线程执行。

`/api/status` 的 `script` 返回源码编译次数、字节码大小、调用次数及运行时创建/复用/回收、活跃/空闲计数，便于观察优化是否生效。

`onStart({})` 用于启动时校验；`onRequest(request)` 用于网站/自定义路由，输入含 method、url、body、ip、host、secure、mode 和过滤后的 headers。管理入口、身份认证和保留 API 不可被脚本替换。请求体上限 64 KiB。

返回 `{}` 继续正常路由，可返回以下一种结果：

- `{allow:false,message:"..."}` 拒绝请求。
- `{status:200,contentType:"text/plain",body:"...",headers:{"X-Example":"..."}}` 返回有界响应。
- `{file:"/public.txt"}` 通过正常下载链读取文件。
- `{rewrite:"/index.html"}` 使用受检静态路径；禁止重写到管理路由。
- `{write:{path:"/note.txt",text:"...",replaceVersion:"..."}}` 通过正常 COW 上传链写入。请求必须为 POST/PUT，且具备登录、写 token、目录权限和额度；不会因脚本存在而提权。

`onFileOperation(event)` 接收 operation、path、size、ip、host、mode，可返回 `{allow:false,message:"..."}` 进一步限制上传、读取、复制、删除、移动、恢复及提供方写操作。下载、预览、P2P 加入/发送和受控文件响应经过读取检查。脚本不能解除配置冻结。此嵌入层用于可信主机扩展，不是允许访客运行任意不可信 JavaScript 的服务。
